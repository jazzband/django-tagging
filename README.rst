==============
Django Tagging
==============

This is a generic tagging application for Django projects. This repository is
deprecated. Please see: https://github.com/ccnmtl/django-tagging

Note that this application version requires Python 3.11 or later, and Django
4.2 or later. You can obtain Python from http://www.python.org/ and
Django from http://www.djangoproject.com/.
